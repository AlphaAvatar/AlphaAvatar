# AlphaAvatar 缺陷记录

这里记录当前已知缺陷和已修复项。复现细节和历史验证见 [2A 开发日志](agent-logs/2026-10/2026-10-25/claude-code-2a-zh.md)、[Doctor 开发日志](agent-logs/2026-11/2026-11-03/claude-code-doctor-zh.md)及 [Context 开发日志](agent-logs/2026-11/2026-11-04/claude-code-context-zh.md)。设计限制和延期的产品决策与已确认缺陷分开记录。

## 已知缺陷

| 编号 | 问题 | 当前状态 |
| --- | --- | --- |
| KD-7 | 工具默认审批行为与部分示例文档不一致。 | 待单独审查工具执行授权和用户确认策略。 |
| O-10 | 缺少 `voice.stt.model` 时，配置检查可能通过，直到装配会话才报错。 | Doctor 可定位到 `session.start`。静态校验待统一。 |
| O-11 | 离线且模型缺失时，模型解析可能留下空缓存目录和锁文件。 | 待修复。 |
| KD-19 | 两句话在同一个语音段里时，分段 STT（`openai_segment` / `gpt-4o-transcribe`）的终稿只有第一句。可重复：2026-11-07 Doctor `voice` 5 轮丢 4 轮，此前 10 轮丢 9 轮；被丢的都是固定样本的第二句。音频完整覆盖两句，终稿被 Turn 采用，但缺这一句。 | 已定位到端点返回的文字，修复方案待定。2026-11-07 的探针核对了 5 段：进入 STT 的 PCM、SegmentJob、编码 WAV 和实际上传的文件逐字节一致，两句都在上传的音频里；端点返回的 delta 和 `transcript.text.done` 已经只有第一句，终稿和 Turn 如实采用。用同一 WAV 和原始样本文件直连 20 次，两句都在的只有 5 次（流式 2/10、非流式 3/10）。修复点在请求的模型或参数，待用户决定对照方案。两句样本和严格判定保留。 |
| KD-20 | 分段 STT 在收到 `transcript.text.done` 后中断并关闭响应流，httpx 因响应体未读完而丢弃连接：同一会话里每个语音段的请求都新建 TCP 和 TLS 连接。 | 离线确认（本地端点：中断时 3 次请求 3 次新建连接，读完后只有第 1 次新建）。待决定修复。真实服务测得每段的建连加 TLS 约 9～13 ms（2026-11-07，`stt_connect`、`stt_tls`）。 |

## 已修复

| 编号 | 问题 | 修复 |
| --- | --- | --- |
| KD-1～KD-3 | 配置校验创建工作区、修改环境变量或初始化向量库，MCP 凭据进入进程环境。 | 校验只生成配置快照，资源由启动流程管理。 |
| KD-4、KD-5 | Persona LanceDB 用户筛选未转义，保存错误未完整传播。 | 校验并转义筛选值，显式处理保存失败。 |
| KD-6 | 被动 Memory 检索的完成状态不完整。 | 在完成边界记录诊断状态。 |
| KD-8、KD-9 | Health 默认监听所有网卡，Host 另有重复诊断模块。 | 默认监听回环地址，移除重复模块。 |
| KD-10 | 身份改绑可能影响旧工作区和画像增量。 | 改绑移除磁盘迁移，画像按参与者隔离并保留已提交轮次的身份历史。 |
| KD-11～KD-13 | 失败 Runner 连带拒绝健康方法，取消准备中的 TTS 被误报为失败，打断后漏计已交付音频。 | 按方法准入，区分取消和失败，并按交付证据对齐音频。 |
| KD-14 | VAD 积压导致语音前缀丢失，余段仍被作为完整语音发布。 | 缺口后先恢复可信的静音或结束边界，再接纳新的语音段。 |
| KD-15、KD-16 | Host 日志 socket 启动失败留下目录，关闭时可能遗漏末条日志。 | 失败时回收目录，关闭前有界排空记录。 |
| KD-17 | 已决定回应的语音轮在短暂等待 STT 后被取消，迟到的有效终稿无法提交。 | 默认在 0.75 秒记录仍待转录，候选保留独立输入边界。同轮按片段记录终稿和失败，全部结算或到达 3 秒期限后，Context 将有效转录和标明缺失片段的系统提示一起交给模型，并保留相应历史。软观察点已真实复验（2026-11-07：20 轮中 2 轮终稿晚于 0.75 秒，仍正常提交）；3 秒硬期限及其后同一输入源的恢复离线通过（迟到旧终稿按其退役片段拒收，不进入新 Turn）；硬期限的真实链路待验证。 |
| KD-18 | 每轮请求都重发 History 中的全部图片，累计内联字节超过 Responses `max_inline_bytes` 后，此后每一轮都被拒，纯文字轮也一样。 | History 仍完整保存。请求把历史图片（用户消息和工具输出）在原位置换成 `<image_not_replayed />`，只有本轮图片内联发送。 |
| O-1、O-3、O-7、O-13 | Runner 启动取消、长 Unix socket 路径、MCP 配置错误脱敏和测试事件循环回收存在缺口。 | 修复对应取消、路径、脱敏和测试回收边界。 |
