# AlphaAvatar v0.6.7 发布说明

### 亮点

AlphaAvatar v0.6.7 引入了新的、**由 AlphaAvatar 自己拥有的多模态轮次判断与语义寻址架构**。

轮次决定不再从 LiveKit 转写回调中间接推断。语音活动、语音片段、转写文本、寻址证据、说完判断评估和最终轮次决定，现在都经由 AlphaAvatar 自己拥有的运行时契约流转。

本版本以**语义寻址**取代了以前的声学唤醒路径。一个轻量的本地模型根据配置的 Avatar 身份、最近的转写上下文和对话焦点，评估当前对话是否是对 Avatar 说的。当前的参考实现通过本地 CPU 推理使用量化的 Qwen3-0.6B 模型，而 Router 契约保持独立于任何特定的模型或 Hugging Face 仓库。

对话焦点按说话人分别维护。明确的 `AVATAR` 或 `NON_AVATAR` 证据会更新焦点，而 `UNKNOWN` 弃权并保留现有上下文。这样 AlphaAvatar 在纯音频对话中可以自然地保持参与，在说话人明显转向另一个人时转为被动，并在再次被叫到时恢复参与。

v0.6.7 还将环境标注提升为有序的**感知事件**，用类型化引用规范化感知身份和谱系，引入带修订号的多模态轮次候选，并新增由标注驱动的 `AvatarTurnController`，用于精确的已提交轮次快照。

结果是一条耦合更低、异步、全双工的交互链路，其中：

* VAD 判断语音活动；
* STT 判断说了什么；
* 语义寻址判断是在对谁说话；
* Smart Turn 判断当前语音是否说完；
* 寻址融合合并相互独立的证据；
* Router 策略决定保持等待、提交、保持被动、打断还是取消；
* Avatar 拥有最终的轮次快照和回复触发。

### 新增内容

#### 语义寻址

* 以基于转写的语义寻址取代声学关键词唤醒。
* 新增 `SemanticAddressingModelBase`，作为与模型无关的推理边界。
* 新增 `SemanticAddressingProcessor`。
* 新增 `AVATAR`、`NON_AVATAR` 和 `UNKNOWN` 寻址标签。
* 语义推理使用 Avatar 身份和别名、最近的对话历史、当前轮次的转写片段以及对话焦点。
* 每个已完成的语音片段进行一次语义评估。
* `UNKNOWN` 表示弃权，而不是指向另一个受话对象的证据。
* 语义评估通过 AlphaAvatar 的常驻推理运行时异步执行。
* 跨越轮次边界的过期结果会被拒绝。
* 轮次判断可以短暂等待所需的寻址证据，而不阻塞感知处理。
* 当前的本地参考实现使用 Qwen3-0.6B Q8_0，采用兼容 llama.cpp 的 CPU 推理以及二元 `0`／`1` token logits。
* 语义寻址接口不绑定当前模型，随着更新的模型出现，可以独立替换。

#### 对话焦点

* 新增按说话人的对话焦点。
* 明确的 `AVATAR` 证据把焦点移到 Avatar。
* 明确的 `NON_AVATAR` 证据把焦点从 Avatar 移开。
* `UNKNOWN` 保留现有焦点。
* 对话焦点作为独立的寻址证据发布，仅在缺少更强的当前证据时作为兜底使用。
* 在没有明确证据或先前焦点时，纯音频交互默认视为对 Avatar 说的对话。
* 清晰的 `NON_AVATAR` 证据可以抑制纯音频回复。
* 含糊的语音不会自动把对话从 Avatar 移开。

#### 多模态轮次判断

* 新增带修订号、按说话人划分的轮次候选。
* 新增不可变的 `TurnTakingEvidence` 和 `TurnTakingAssessment` 契约。
* 新增明确的 `HOLD`、`COMMIT`、`PASSIVE`、`INTERRUPT`、`PROACTIVE_CHECK` 和 `CANCEL` 动作。
* 新增与模型评估分离的确定性轮次判断策略。
* 新增寻址融合，用于合并独立产生的寻址证据。
* `UNKNOWN` 证据在融合中弃权，而不是成为目标。
* 对话焦点证据作为兜底，排在当前的明确证据之后。
* 置信度相近的冲突目标按保守方式解决。
* 候选的修订号使过期的模型评估失效。
* 必需的寻址生产者独立于其分类结果公开自己的就绪状态。
* 寻址仍未解决时，纯音频交互保留面向 Avatar 的通道语义。
* 在正常解决和超时解决期间，明确的非 Avatar 证据仍被遵守。

#### Smart Turn 说完评估

* 新增本地的 Smart Turn v3 说完判断模型。
* 说完判断独立于语义寻址。
* Smart Turn 消费候选级别的 PCM 证据，而不是转写文本的标点。
* 连续的语音片段可以组成一个说完判断候选。
* 片段之间的时间间隔被保留。
* 较长的候选只保留配置的最后一段音频窗口。
* Smart Turn 通过 AlphaAvatar 的常驻推理运行时运行。
* 说完判断模型只返回评估，不能直接触发 Avatar 回复。

#### 全双工打断

* 开口打断与说完判断分离。
* 新的语音开始时，Avatar 输出可以立即停止，无需等待语义寻址。
* 打断之后，同一个用户候选继续收集语音和转写证据。
* 随后语义寻址可以确定该语音应产生 `COMMIT` 还是 `PASSIVE`。
* 助手输出通道和临时输出通道获得明确的打断控制。
* 打断不再意味着新的语音已被认定为面向 Avatar。

#### 感知事件与类型化谱系

* 将环境标注提升为有序的感知事件。
* 新增类型化的 `AnnotationKind`。
* 标注消费者现在各自维护独立的游标。
* 保留期造成的缺口会明确标出。
* 新增 `PerceptionSourceRef`、`PerceptionSegmentRef` 和 `PerceptionEntityRef`。
* 语音观测和转写观测共享类型化的片段谱系。
* 传输参与者和感知实体使用明确的类型化引用。
* 来源世代防止来自不同重连生命周期的观测被合并。
* 对保留元数据字段的校验，防止核心身份字段以任意字符串的形式重复出现。

#### 精确的轮次快照

* 新增在精确的感知事件序号处捕获快照。
* 新增由标注驱动的 `AvatarTurnController`。
* 最终的 `COMMIT` 决定创建不可变的 `TurnSnapshot` 实例。
* 轮次快照保留主体、受话对象、决定置信度、原因和相关观测。
* 轮次决定之后到达的事件不会泄漏到已提交的上下文中。
* 对同一已提交输入的重复决定复用已有的快照。
* `PASSIVE`、`HOLD` 和 `CANCEL` 不会创建 Avatar 用户轮次。

#### Router 架构

* 将共享的公开交互契约从 `alphaavatar.agents.interaction` 重命名为 `alphaavatar.agents.router`。
* Router 公开契约与具体的 Router 插件实现现在采用相同的领域命名。
* 将音频活动重组为单独的处理器模块。
* 音频活动、转写、语义寻址、轮次判断、合成和转写文本同步仍是各自独立管理的处理器。
* 观测消费和推理执行保持完全异步。
* CPU 密集的本地推理通过常驻推理进程，在会话事件循环之外运行。
* Router 处理器保持独立于传输和 Provider。

当前的处理器架构为：

```text
PerceptionRuntime
        ↓
AudioActivityProcessor
        ↓
SPEECH_FRAME / SPEECH_SEGMENT
        ↓
SpeechTranscriptionProcessor
        ↓
TRANSCRIPT_SEGMENT
        ↓
SemanticAddressingProcessor
        ↓
Addressing Evidence / Conversation Focus
        ↓
Addressing Fusion
        +
Smart Turn Assessment
        ↓
TurnTakingProcessor
        ↓
HOLD / COMMIT / PASSIVE / INTERRUPT / CANCEL
        ↓
AvatarTurnController
        ↓
TurnSnapshot
        ↓
Avatar Context / Model
```

#### 视觉轮次判断边界

* 保留视觉寻址和纯视觉轮次判断接口。
* 视觉证据使用与语义证据相同的寻址契约。
* 未来的视线、面部朝向、手势、视觉注意力、场景事件和主动轮次处理器，可以在不改变轮次判断核心的情况下引入。
* 本版本默认不启用任何具体的纯视觉主动行为。

#### Persona 模型打包

* 将 Speaker Vector 和 Speaker Attribute ONNX 模型从旧分支迁移到独立的 Hugging Face 模型仓库。
* Speaker Vector 现在使用 `AlphaAvatar/persona-speaker-vector-onnx`。
* Speaker Attribute 现在使用 `AlphaAvatar/persona-speaker-attribute-onnx`。
* Persona 模型缓存按模型用途分开。
* 将 Speaker Attribute 的性别标签顺序更正为 `child`、`female`、`male`。
* 新增上游 Speaker Attribute 模型所需的波形归一化。
* Speaker Vector 模型的预处理保持不变。
* 模型修订版本固定到不可变的 Hugging Face commit。

### 移除

* 移除了以前的声学唤醒检测器契约和 Router 实现。
* 从 Router 中移除了 Sherpa 关键词检测依赖。
* 移除了 `InvocationDetectorBase`、唤醒 schema、唤醒处理器接线以及 `AddressingEvidenceKind.INVOCATION`。
* 从当前的 AlphaAvatar 轮次决定链路中移除了 LiveKit 文本轮次检测。
* 移除了旧的 interaction 包命名，改用 `alphaavatar.agents.router`。
* 移除了旧的 Persona 模型分支引用。

### 说明

* 语义寻址有意与模型无关。当前的 Qwen3-0.6B Q8_0 模型是初始的本地基线，预计会独立于 Router 架构演进。
* 当前的基线语义寻址模型不应被视为多说话人交互的最终准确率目标。
* 在没有明确相反证据时，纯音频交互有意保留面向 Avatar 的先验。
* `UNKNOWN` 语义寻址结果不表示 `NON_AVATAR`。
* 纯视觉主动轮次行为在本版本中仍是扩展点，而不是具体功能。
* 共用麦克风的多说话人交互要做到准确，仍依赖上游的说话人和实体分离。
* LiveKit 仍是默认的 RTC 传输，也是临时的最终 Assistant 交付适配器。
* AlphaAvatar 现在独立于 LiveKit 拥有权威的用户轮次决定。
* Perception 和 Output 流仍是有界的实时缓冲区，而不是持久的媒体存储。
* 内部 API 继续优先保证快速的架构迭代，而不是向后兼容。

### 架构方向

v0.6.7 在感知、评估、寻址、策略和动作之间建立了更清晰的分离：

```text
Speech activity
      ↓
VAD

Speech content
      ↓
STT

Current-turn context
      +
Conversation focus
      ↓
Semantic Addressing
      ↓
AVATAR / NON_AVATAR / UNKNOWN

Candidate audio
      ↓
Smart Turn
      ↓
P(end of turn)

Semantic / Focus / Future Visual Evidence
      ↓
Addressing Fusion
      ↓
Resolved Addressee

Endpoint Assessment
      +
Resolved Addressee
      +
Runtime Policy
      ↓
HOLD / COMMIT / PASSIVE / INTERRUPT / CANCEL
```

现在各项架构职责已经明确：

* `avatar-core` 拥有与传输无关的观测、标注、感知事件、类型化来源身份、片段谱系、保留、计时和精确的历史 cutoff。
* Router 拥有实时语音路由、转写路由、语义寻址、对话焦点、寻址融合、说完判断协调、打断和最终轮次决定。
* Voice 插件拥有 VAD、STT 和 TTS 能力，不拥有用户轮次策略。
* Persona 拥有说话人、人脸、身份和用户上下文处理。
* Avatar 拥有已提交的轮次快照、上下文构造、模型编排和回复发起。
* Output Runtime 拥有与传输无关的 Assistant 输出和临时输出状态。
* 入口程序拥有 RTC 转换和特定于传输的交付。
* 模型提供评估；由确定性的 AlphaAvatar 运行时策略负责动作。

AlphaAvatar v0.6.7 让实时交互从由转写驱动的轮次完成，转向一个明确、模块化的多模态交互运行时，为语义寻址、多说话人对话、更丰富的全双工行为，以及未来的视觉和主动轮次判断而设计。
