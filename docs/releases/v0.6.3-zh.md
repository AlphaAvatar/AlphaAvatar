## AlphaAvatar v0.6.3 发布说明

[English](v0.6.3.md)

### 亮点

AlphaAvatar v0.6.3 首次为**图感知的记忆检索**奠定基础。

本版本围绕更清晰的 `MemoryItem` 模型、多对象归属、图节点提及、会话作用域的本地身份键，以及基于 LanceDB 的图感知检索，重构了 Memory 插件。它为未来的多模态 ENV 记忆提取做好准备，同时本版本仍专注于稳定的对话／工具记忆和图检索基础设施。

### 新增内容

* 新增图感知的 `MemoryItem` 支持：

  * `object_ids` 取代单对象的记忆归属。
  * 记忆条目现在可以携带 `graph_nodes` 和 `graph_links`。
  * 记忆内容仍是事实来源，图节点作为检索锚点。

* 新增图节点提及的提取：

  * `PatchOp.node_mentions` 让记忆提取器提供轻量的图锚点。
  * 图节点和图链接由运行时逻辑构建，而不是由模型直接生成。
  * prompt 输出经过简化，使 `PatchOp.value` 保持干净、便于人阅读。

* 新增会话作用域的本地图键：

  * `face:tmp_1`、`voice:speaker_0` 和 `object:cup_1` 等本地检测器 ID 按会话限定作用域。
  * 这可防止同一临时 ID 出现在不同会话中时造成跨会话的身份污染。

* 新增图查找基础设施：

  * 新增 `GraphLookup`，用于别名解析和图邻居扩展。
  * 支持在查询时展开别名，而不是立即重写向量数据库。
  * 支持 0 跳以及可选的 1 跳图扩展。

* 新增 LanceDB 图感知检索：

  * LanceDB 现在同时存储 `memory_item` 行和 `graph_node` 出现行。
  * 图节点行关联回 `memory_id`。
  * 新增按 `node_keys` 批量检索，用于精确查找图节点。
  * 新增图节点语义检索。
  * 新增按 `object_ids` 过滤对象。

* 新增 MemoryBase 图 API：

  * 新增公开的记忆接口 `search_by_graph_node()`。
  * 新增 `save_graph_aliases()`，作为面向未来、供 Persona、ENV 记忆、渠道及其他插件使用的身份／实体合并接口。

* 更新记忆提取 prompt：

  * 用统一的 `SESSION CONTENT` 取代仅针对轮次的表述。
  * 会话内容可以包括对话、工具摘要、运行时上下文以及未来的 ENV 记忆上下文。
  * 从提取输出中移除由模型控制的 `evidence` 和 `extra_data`。
  * 证据、对象 ID、时间戳、会话 ID 和运行时元数据现在由运行时逻辑负责。

### 说明

* ENV 记忆提取有意推迟到 v0.6.4。
* Persona／身份合并钩子尚未启用；`save_graph_aliases()` 作为接口基础加入。
* 现有的本地 LanceDB 记忆表可能需要重建，因为 schema 已从单个 `object_id` 改为 `object_ids_json`，并新增了图节点出现行。

### 内部方向

v0.6.3 将 Memory 插件确立为图感知的检索层：

* LLM 提取干净的记忆文本和图锚点。
* 运行时负责会话作用域、证据、对象 ID、图构建和别名逻辑。
* LanceDB 同时索引记忆条目和图节点出现记录。
* 未来的 ENV 记忆可以接入同一条“记忆条目 + 图节点 + 检索”路径。
