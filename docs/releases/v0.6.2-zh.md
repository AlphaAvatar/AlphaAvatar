# AlphaAvatar v0.6.2 发布说明

AlphaAvatar **v0.6.2** 着重对运行时和配置做了一次大规模清理，引入统一的 Provider 层，并为更丰富的多用户、多模态、感知会话的工作流做好准备。

## 亮点

### 统一的 Provider 层

本版本在 `alphaavatar.agents.providers` 下引入新的 Provider 抽象，AlphaAvatar 插件可以通过统一的、基于任务的接口调用 LLM 和 embedding 模型，而不必直接依赖某个特定供应商的客户端。

Provider 层现在支持：

* 任务级 LLM 配置
* 结构化输出调用
* Provider 用量归一化
* prompt 和响应追踪
* token 用量和延迟记录
* 基于 Provider 创建 embedding 模型

Memory 和 Persona 的提取逻辑现在可以通过 Provider 任务配置，例如：

```yaml
memory.conversation_delta
memory.tool_delta
persona.profile_delta
```

这样更容易在 OpenAI、OpenRouter、Gemini、Claude 或未来的其他供应商之间切换，无需重写插件内部实现。

### Provider 追踪与用量跟踪

Provider 调用现在支持结构化追踪，用于调试和分析。每次任务调用可以记录：

* 任务名称
* 供应商和模型
* prompt 哈希
* prompt 版本
* 延迟
* token 用量
* 可用时的缓存／推理 token 元数据
* 错误状态
* 会话元数据

追踪记录按会话和任务名称组织，便于检查和比较 Memory、Persona 及未来运行时组件的运行时行为。

### 基于 Provider 的 Embedding

Embedding 的创建已移入 Provider 系统。Memory、Persona 和 MCP 等基于 VDB 的模块现在可以用统一的结构配置 embedding：

```yaml
embedding:
  provider: openai
  model: text-embedding-3-small
```

旧的直接 embedding 工厂路径已移除，改为显式地基于 Provider 创建。

### 运行时结构重构

本版本将运行时状态与静态配置分离。

AlphaAvatar 现在引入专门的运行时层，用于：

* 会话运行时
* 上下文运行时
* 参与者／用户运行时状态
* 会话路径
* 用户路径迁移

这为多用户房间会话做好准备：一个会话可以包含多个参与者，每个参与者解析为不同的用户身份。

### 多参与者会话基础

会话运行时现在围绕参与者设计，不再假设每个会话只有一个 `user_id`。

一个会话现在可以跟踪：

* 会话 ID
* 主参与者
* 多个参与者
* 参与者到用户身份的解析
* 用户路径更新
* 待执行的用户路径迁移

这为未来多说话人、多人脸和多用户的记忆流程奠定基础。

### 更清晰的 Avatar 目录布局

运行时目录布局已经理清：

```text
data/
  sessions/
  memory/
  graph/
  artifacts/

users/
  {user_id}/

env/
  ...
```

会话级产物、Provider 追踪记录、记忆候选和未来的多模态观测现在归入会话级或 Avatar 级数据目录，用户目录则留给参与者身份和运行时状态。

### 嵌套配置格式

AlphaAvatar 的配置格式已从扁平键重组为按模块划分的嵌套结构。

例如：

```yaml
llm:
  plugin: openai
  model: gpt-4o-mini

voice:
  stt:
    plugin: openai
    model: gpt-4o-transcribe

memory:
  provider:
    conversation_delta_task: memory.conversation_delta
    tool_delta_task: memory.tool_delta
```

随着 AlphaAvatar 的发展，这让配置文件更易于阅读、维护和扩展。

### 插件生命周期清理

运行时插件的初始化已按更清晰的生命周期模型整理。

插件现在可以分开处理：

* 对象构造
* 会话启动
* 会话关闭
* 保存／清理行为

这减少了 `AvatarEngine.on_enter()` 中的初始化逻辑，使 Memory、Persona、Vision 及未来的插件更易管理。

## 不兼容变更／迁移说明

本版本包含内部配置和运行时结构的变更。

现有的扁平 YAML 配置，例如：

```yaml
llm_plugin: openai
llm_model: gpt-4o-mini
```

应迁移为新的嵌套形式：

```yaml
llm:
  plugin: openai
  model: gpt-4o-mini
```

Embedding 配置现在应显式写明：

```yaml
embedding:
  provider: openai
  model: text-embedding-3-small
```

不再推荐使用旧的直接 embedding 模型配置路径。

## 总结

AlphaAvatar v0.6.2 是以基础设施为重点的版本，改进了 Provider 抽象、运行时状态组织、Provider 追踪、embedding 配置和插件生命周期边界。

这些变更为 AlphaAvatar 的下一阶段做好准备：更健壮的多模态记忆运行时、会话级事件存储、多用户身份处理，以及基于图的长期上下文。
