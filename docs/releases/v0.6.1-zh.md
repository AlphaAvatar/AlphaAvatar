## AlphaAvatar v0.6.1

本版本为 AlphaAvatar 的 Persona 系统加入视觉身份支持，并改进实时多模态身份解析。

### 亮点

- 为 Persona 插件新增**视觉身份支持**。
- 集成基于摄像头输入的实时**人脸检测和人脸向量提取**。
- 通过 Persona VDB 层新增**人脸向量匹配、检索和持久化**。
- 新增**说话人与人脸身份融合**，语音和人脸信号可以解析并丰富同一个用户画像。
- 改进将临时用户解析为持久用户身份时的 Persona 缓存行为。
- 新增基于人脸的画像属性更新，例如估计的年龄段和性别。
- 减少高频的实时人脸更新日志。
- 修复与 Persona 运行时状态、身份合并、VDB 加载／保存和多模态身份更新相关的若干缺陷。
- 改进 **Persona** 和 **Memory** 插件的 README 文件，使安装、配置和使用说明更清晰。

### 说明

本版本是迈向更具持续性的多模态个人 AI 助手的重要一步。AlphaAvatar 现在可以同时利用语音和视觉信号，在实时会话中更好地了解正在与谁交互。
