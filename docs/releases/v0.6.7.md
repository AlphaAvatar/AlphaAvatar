# AlphaAvatar v0.6.7 Release Notes

### Highlights

AlphaAvatar v0.6.7 introduces a new **AlphaAvatar-owned multimodal turn-taking and semantic addressing architecture**.

Turn decisions are no longer inferred indirectly from LiveKit transcription callbacks. Speech activity, speech segments, transcripts, addressing evidence, endpoint assessments, and final turn decisions now flow through AlphaAvatar-owned runtime contracts.

This release replaces the previous acoustic invocation path with **Semantic Addressing**. A lightweight local model evaluates whether the current conversation is directed at the Avatar using configured Avatar identities, recent transcript context, and conversation focus. The current reference implementation uses a quantized Qwen3-0.6B model through local CPU inference, while the Router contract remains independent from any specific model or Hugging Face repository.

Conversation focus is maintained independently for each speaker. Explicit `AVATAR` or `NON_AVATAR` evidence updates focus, while `UNKNOWN` abstains and preserves the existing context. This allows AlphaAvatar to remain naturally engaged in audio-only conversations, become passive when the speaker clearly turns to another person, and resume when the Avatar is addressed again.

v0.6.7 also promotes environment annotations into ordered **Perception Events**, normalizes perception identity and lineage with typed references, introduces revisioned multimodal turn candidates, and adds an annotation-driven `AvatarTurnController` for exact committed-turn snapshots.

The result is a lower-coupled, asynchronous, full-duplex interaction pipeline where:

* VAD determines speech activity;
* STT determines what was said;
* Semantic Addressing determines who is being addressed;
* Smart Turn determines whether the current speech is complete;
* Addressing Fusion combines independent evidence;
* Router policy decides whether to hold, commit, remain passive, interrupt, or cancel;
* Avatar owns the final turn snapshot and response trigger.

### What's New

#### Semantic Addressing

* Replaced acoustic keyword invocation with transcript-based Semantic Addressing.
* Added `SemanticAddressingModelBase` as a model-independent inference boundary.
* Added `SemanticAddressingProcessor`.
* Added `AVATAR`, `NON_AVATAR`, and `UNKNOWN` addressing labels.
* Semantic inference uses Avatar identities and aliases, recent conversation history, current-turn transcript segments, and conversation focus.
* One semantic assessment is performed for each completed speech segment.
* `UNKNOWN` represents abstention rather than evidence for another addressee.
* Semantic assessments run asynchronously through AlphaAvatar's persistent inference runtime.
* Stale results are rejected across turn boundaries.
* Turn Taking can wait briefly for required addressing evidence without blocking perception processing.
* The current local reference implementation uses Qwen3-0.6B Q8_0 with llama.cpp-compatible CPU inference and binary `0` / `1` token logits.
* The Semantic Addressing interface is not tied to the current model and can be replaced independently as newer models become available.

#### Conversation Focus

* Added per-speaker conversation focus.
* Explicit `AVATAR` evidence moves focus to the Avatar.
* Explicit `NON_AVATAR` evidence moves focus away from the Avatar.
* `UNKNOWN` preserves the existing focus.
* Conversation focus is published as independent addressing evidence and used only as fallback when stronger current evidence is unavailable.
* Audio-only interaction defaults to Avatar-directed conversation when no explicit evidence or previous focus exists.
* Clear `NON_AVATAR` evidence can suppress an Audio-only response.
* Ambiguous speech does not automatically move the conversation away from the Avatar.

#### Multimodal Turn Taking

* Added revisioned, speaker-scoped turn candidates.
* Added immutable `TurnTakingEvidence` and `TurnTakingAssessment` contracts.
* Added explicit `HOLD`, `COMMIT`, `PASSIVE`, `INTERRUPT`, `PROACTIVE_CHECK`, and `CANCEL` actions.
* Added deterministic Turn Taking policy separate from model assessment.
* Added Addressing Fusion for independently produced addressing evidence.
* `UNKNOWN` evidence abstains from fusion rather than becoming a target.
* Conversation-focus evidence acts as fallback behind current explicit evidence.
* Similar-confidence conflicting targets resolve conservatively.
* Candidate revisions invalidate stale model assessments.
* Required addressing producers expose readiness independently from their classification result.
* Audio-only interaction retains Avatar-directed channel semantics when addressing remains unresolved.
* Explicit non-Avatar evidence remains respected during normal and timeout resolution.

#### Smart Turn Endpoint Assessment

* Added a local Smart Turn v3 endpoint model.
* Endpoint completion is independent from semantic addressing.
* Smart Turn consumes candidate-level PCM evidence rather than transcript punctuation.
* Consecutive speech segments can form one endpoint candidate.
* Temporal gaps between segments are preserved.
* Long candidates retain only the configured final audio window.
* Smart Turn runs through AlphaAvatar's persistent inference runtime.
* Endpoint models return assessments only and cannot directly trigger Avatar responses.

#### Full-Duplex Interruption

* Speech-start interruption is separated from endpoint completion.
* Avatar output can stop immediately when new speech begins without waiting for Semantic Addressing.
* The same user candidate continues collecting speech and transcript evidence after interruption.
* Semantic Addressing can subsequently determine whether the speech should produce `COMMIT` or `PASSIVE`.
* Assistant and transient output lanes receive explicit interruption controls.
* Interruption no longer implies that the new speech has already been identified as Avatar-directed.

#### Perception Events and Typed Lineage

* Promoted environment annotations into ordered Perception Events.
* Added typed `AnnotationKind`.
* Annotation consumers now maintain independent cursors.
* Retention gaps are explicit.
* Added `PerceptionSourceRef`, `PerceptionSegmentRef`, and `PerceptionEntityRef`.
* Speech and transcript observations share typed segment lineage.
* Transport participants and perceived entities use explicit typed references.
* Source generations prevent observations from different reconnect lifecycles from being merged.
* Reserved metadata validation prevents core identity fields from being duplicated as arbitrary strings.

#### Exact Turn Snapshots

* Added snapshot capture at an exact Perception Event sequence.
* Added annotation-driven `AvatarTurnController`.
* Final `COMMIT` decisions create immutable `TurnSnapshot` instances.
* Turn snapshots preserve actor, addressees, decision confidence, reason, and relevant observations.
* Events arriving after a turn decision cannot leak into the committed context.
* Duplicate decisions for the same committed input reuse the existing snapshot.
* `PASSIVE`, `HOLD`, and `CANCEL` do not create Avatar user turns.

#### Router Architecture

* Renamed the shared public interaction contracts from `alphaavatar.agents.interaction` to `alphaavatar.agents.router`.
* Router public contracts and concrete Router plugin implementations now align under the same domain naming.
* Reorganized Audio Activity into its own processor module.
* Audio activity, transcription, semantic addressing, turn taking, synthesis, and transcript synchronization remain independently managed processors.
* Observation consumption and inference execution remain fully asynchronous.
* CPU-heavy local inference runs outside the session event loop through persistent inference processes.
* Router processors remain transport-independent and provider-independent.

The current processor architecture is:

```text
PerceptionRuntime
        ↓
AudioActivityProcessor
        ↓
SPEECH_FRAME / SPEECH_SEGMENT
        ↓
SpeechTranscriptionProcessor
        ↓
TRANSCRIPT_SEGMENT
        ↓
SemanticAddressingProcessor
        ↓
Addressing Evidence / Conversation Focus
        ↓
Addressing Fusion
        +
Smart Turn Assessment
        ↓
MultimodalTurnTakingProcessor
        ↓
HOLD / COMMIT / PASSIVE / INTERRUPT / CANCEL
        ↓
AvatarTurnController
        ↓
TurnSnapshot
        ↓
Avatar Context / Model
```

#### Visual Turn-Taking Boundary

* Retained the visual addressing and visual-only turn-taking interfaces.
* Visual evidence uses the same addressing contracts as semantic evidence.
* Future gaze, face orientation, gesture, visual attention, scene-event, and proactive-turn processors can be introduced without changing the Turn Taking core.
* No concrete visual-only proactive behavior is enabled by default in this release.

#### Persona Model Packaging

* Migrated Speaker Vector and Speaker Attribute ONNX models from legacy branches into independent Hugging Face model repositories.
* Speaker Vector now uses `AlphaAvatar/persona-speaker-vector-onnx`.
* Speaker Attribute now uses `AlphaAvatar/persona-speaker-attribute-onnx`.
* Persona model caches are separated by model purpose.
* Corrected Speaker Attribute gender label ordering to `child`, `female`, `male`.
* Added the waveform normalization required by the upstream Speaker Attribute model.
* Speaker Vector model preprocessing remains unchanged.
* Model revisions are pinned to immutable Hugging Face commits.

### Removed

* Removed the previous acoustic invocation detector contracts and Router implementation.
* Removed Sherpa keyword-spotting dependencies from the Router.
* Removed `InvocationDetectorBase`, invocation schemas, invocation processor wiring, and `AddressingEvidenceKind.INVOCATION`.
* Removed LiveKit text turn detection from the active AlphaAvatar turn-decision path.
* Removed the old interaction package naming in favor of `alphaavatar.agents.router`.
* Removed the legacy Persona model branch references.

### Notes

* Semantic Addressing is intentionally model-independent. The current Qwen3-0.6B Q8_0 model is an initial local baseline and is expected to evolve independently from the Router architecture.
* The current baseline Semantic Addressing model should not be treated as the final accuracy target for multi-speaker interaction.
* Audio-only interaction intentionally retains an Avatar-directed prior when there is no clear evidence to the contrary.
* `UNKNOWN` Semantic Addressing results do not mean `NON_AVATAR`.
* Visual-only proactive turn behavior remains an extension point rather than a concrete feature in this release.
* Accurate shared-microphone multi-speaker interaction still depends on upstream speaker and entity separation.
* LiveKit remains the default RTC transport and temporary final Assistant delivery adapter.
* AlphaAvatar now owns the authoritative user-turn decision independently from LiveKit.
* Perception and Output streams remain bounded realtime buffers rather than durable media stores.
* Internal APIs continue to prioritize rapid architectural iteration over backward compatibility.

### Architecture Direction

v0.6.7 establishes a clearer separation between perception, assessment, addressing, policy, and action:

```text
Speech activity
      ↓
VAD

Speech content
      ↓
STT

Current-turn context
      +
Conversation focus
      ↓
Semantic Addressing
      ↓
AVATAR / NON_AVATAR / UNKNOWN

Candidate audio
      ↓
Smart Turn
      ↓
P(end of turn)

Semantic / Focus / Future Visual Evidence
      ↓
Addressing Fusion
      ↓
Resolved Addressee

Endpoint Assessment
      +
Resolved Addressee
      +
Runtime Policy
      ↓
HOLD / COMMIT / PASSIVE / INTERRUPT / CANCEL
```

The architectural responsibilities are now explicit:

* `avatar-core` owns transport-independent observations, annotations, perception events, typed source identity, segment lineage, retention, timing, and exact historical cutoffs.
* Router owns realtime speech routing, transcription routing, semantic addressing, conversation focus, addressing fusion, endpoint coordination, interruption, and final turn decisions.
* Voice plugins own VAD, STT, and TTS capabilities without owning user-turn policy.
* Persona owns speaker, face, identity, and user-context processing.
* Avatar owns committed turn snapshots, context construction, model orchestration, and response initiation.
* Output Runtime owns transport-independent Assistant and transient output state.
* Entrypoints own RTC conversion and transport-specific delivery.
* Models provide assessments; deterministic AlphaAvatar runtime policy remains responsible for actions.

AlphaAvatar v0.6.7 moves realtime interaction from transcription-driven turn completion toward an explicit, modular, multimodal interaction runtime designed for semantic addressing, multi-speaker conversation, richer full-duplex behavior, and future visual and proactive turn-taking.
